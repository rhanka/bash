# Lot L1a-1 — Memory module interface

Lot spec for the build lane (Room 2). Sources of authority: `spec/SPEC_EVOL_BASH_SANDBOX.md` ("EVOL":
decisions D2, D6, D7, D17; gate G6 of Annex C; Annex B) and `plan/PLAN_BASH_SANDBOX_V1.md` (lot L1a-1).
It builds on lot L0 as specified in `spec/lots/L0.md` (the kernel crate, `tools/build.mjs`,
`tools/check.mjs`, gates G1-G8) and assumes nothing about L0's internals beyond that spec. Where this
document and EVOL differ, stop and raise a spec issue.

- **Size.** 2 points. **Builder.** Sonnet 5.5; fallback Gemini 4 Argon. **Review.** Carbon, full review of
  every PR, dispatched on a green `make check`.
- **Branch.** `feat/l1a1-mem-interface`, worktree `tmp/l1a1-mem-interface`.
- **Outcome.** The module `kernel::mem` with its **final public interface** and a deliberately simple
  implementation. L1b builds the contract skeleton against it while L1a-2 replaces the implementation
  (free-list allocator, chunked storage, reserve) without changing a signature given here.

## 1. Lane rules

1. No reference source and no reference package in the worktree. No network.
2. No crate from a registry: `Cargo.lock` stays workspace-only.
3. `unsafe` is allowed only inside `kernel/src/mem/`; every `unsafe` block carries a `// SAFETY:` comment
   stating the invariant it relies on.
4. Commits through `make commit`, no attribution trailer. English.

## 2. Scope

In scope: the module, its tests, and the two small pipeline extensions of section 7.
Out of scope (L1a-2): the free-list allocator, fragmentation and retention behaviour, the unwinding
reserve, headroom accounting of transfer buffers, chunked byte storage, a balanced tree for the map,
weak references. Out of scope (L1b): any contract export, the wiring of `cabi_realloc` as a component
export, the binding module.

## 4. Design rules

- **One door to the heap.** Every heap allocation of the kernel goes through `kernel::mem`. Outside this
  module (and the generated binding module), importing `alloc::vec`, `alloc::string`,
  `alloc::collections`, `alloc::boxed`, `alloc::rc`, `alloc::fmt` or `alloc::borrow::ToOwned` is refused by
  gate G6. Inside the module those types may be used as building blocks, provided no infallible growth
  path is reachable from the public interface.
- **Nothing here aborts on memory pressure.** Every operation that can allocate returns a `MemResult`. The
  only trapping path is `cabi_realloc` (section 5.8), by contract.
- **Two independent limits.** A *budget* is a logical byte cap tied to a named limit of EVOL Annex B
  (string length, output size, filesystem bytes, ...). The *ceiling* is the instance-wide cap on bytes
  obtained from the allocator. Containers charge their budget first, then allocate; the ceiling is
  enforced by the allocator itself. EVOL sizes budgets so that they bind first.
- **Single-threaded.** The kernel runs on one thread; the module's types are neither `Send` nor `Sync`,
  and its global state needs no lock.
- **Same behaviour on both targets.** The module compiles for `wasm32-wasip2` (`no_std`) and for the
  native target (with `std`, for tests). Budget and ceiling logic is target-independent.

## 5. Public interface

All items below are `pub` in `kernel::mem` (re-exported from its submodules). Signatures are normative;
private helpers, field layouts and trait implementations not listed are the builder's choice. Unless
stated, an operation that fails leaves the container unchanged.

### 5.1 Errors

```rust
/// Identifies a named limit of EVOL Annex B. 0 and 1 are reserved here; later lots assign the others.
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct LimitId(pub u16);
impl LimitId {
    pub const CEILING: LimitId = LimitId(0);    // instance memory ceiling
    pub const HEADROOM: LimitId = LimitId(1);   // transfer buffers (accounting completed in L1a-2)
}

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum MemError {
    /// A budget refused the charge. Carries the limit of the budget that refused
    /// (the nearest refusing ancestor when budgets are nested).
    Limit(LimitId),
    /// The allocator refused: the instance ceiling would be exceeded.
    Ceiling,
    /// A size computation overflowed `usize` (for example capacity * element size).
    Overflow,
}
pub type MemResult<T> = core::result::Result<T, MemError>;
```

### 5.2 Instance ceiling

```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum ConfigError { AlreadyConfigured, NotConfigured, BelowCurrent, BelowUsage }

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Usage { pub used: u64, pub ceiling: u64, pub high_water: u64 }

/// Sets the ceiling. Valid once; a second call returns AlreadyConfigured.
/// Returns BelowUsage if `bytes` is below the bytes already in use.
pub fn configure(ceiling_bytes: u64) -> Result<(), ConfigError>;
/// Raises the ceiling. NotConfigured before `configure`; BelowCurrent if `bytes` < current ceiling.
/// Equal to the current ceiling is accepted and changes nothing.
pub fn raise_ceiling(ceiling_bytes: u64) -> Result<(), ConfigError>;
pub fn usage() -> Usage;
```

Before `configure`, the ceiling is a built-in bootstrap value of 1 MiB, enough to receive the first call.
`used` counts bytes currently obtained from the allocator; `high_water` is its maximum since start.
The ceiling logic lives in one wrapper type around an inner allocator, used as the global allocator: on
wasm the inner allocator is the bump allocator of section 6; in native tests it is the system allocator.
An allocation that would take `used` above the ceiling returns null to its caller, which the containers
report as `MemError::Ceiling`.

### 5.3 Budgets

```rust
/// A byte budget. Cloning yields another handle to the same budget.
pub struct Budget { /* private */ }
impl Budget {
    /// A root budget with the given cap, in bytes.
    pub fn root(limit: LimitId, cap: u64) -> MemResult<Budget>;
    /// A child budget: a charge on it is also charged to every ancestor.
    pub fn child(&self, limit: LimitId, cap: u64) -> MemResult<Budget>;
    /// Charges `bytes`. Fails with Limit(id) of the first budget, from this one up to the root,
    /// whose cap would be exceeded; on failure nothing is charged anywhere.
    pub fn charge(&self, bytes: u64) -> MemResult<()>;
    /// Releases `bytes` from this budget and every ancestor. Releasing more than charged is a bug:
    /// debug builds panic, release builds saturate at zero.
    pub fn release(&self, bytes: u64);
    pub fn used(&self) -> u64;
    pub fn cap(&self) -> u64;
    pub fn limit(&self) -> LimitId;
    /// Changes the cap. Lowering it below `used` is allowed; later charges fail until usage drops.
    pub fn set_cap(&self, cap: u64);
}
impl Clone for Budget { /* handle copy, never fails, allocates nothing */ }
```

The memory of a budget node itself is taken from the allocator and is not charged to any budget; creating
a node can therefore fail only with `Ceiling`. A node lives as long as a handle, a child or a container
refers to it.

### 5.4 Charging rule for containers

A container holds a handle to the budget it was created with. It charges
`capacity_in_elements * size_of::<T>()` bytes (plus, for `KBox` and `KRc`, the size of the allocation
actually requested), charges the *difference* before growing, and releases on shrink and on drop. After
the last container of a budget is dropped, `budget.used()` is 0. Zero-sized element types charge nothing.

Growth policy: when more room is needed, the new capacity is the larger of the required capacity and
1.5 times the current one (rounded up), with a minimum of 4 elements; `try_reserve_exact` requests
exactly what is asked. If the budget cannot cover the amortized capacity but can cover the exact need,
the exact need is used.

### 5.5 `TryClone`

```rust
pub trait TryClone: Sized {
    fn try_clone(&self) -> MemResult<Self>;
}
```

Implemented in this lot for: the integer and float primitives, `bool`, `char`, `()`, tuples of up to four
`TryClone` elements, `Option<T: TryClone>`, `KVec<T: TryClone>`, `KString`, `KBox<T: TryClone>`, `KRc<T>`
(a handle copy), `KMap<K: TryClone + Ord, V: TryClone>`. A clone is charged to the same budget as its
source.

### 5.6 Containers

```rust
pub struct KVec<T> { /* private */ }
impl<T> KVec<T> {
    pub fn new_in(budget: &Budget) -> KVec<T>;                       // no allocation
    pub fn with_capacity_in(capacity: usize, budget: &Budget) -> MemResult<KVec<T>>;
    pub fn try_reserve(&mut self, additional: usize) -> MemResult<()>;
    pub fn try_reserve_exact(&mut self, additional: usize) -> MemResult<()>;
    /// On failure the value is dropped and the vector is unchanged.
    pub fn try_push(&mut self, value: T) -> MemResult<()>;
    pub fn try_insert(&mut self, index: usize, value: T) -> MemResult<()>;   // panics if index > len
    pub fn try_extend_from_slice(&mut self, items: &[T]) -> MemResult<()> where T: Copy;
    pub fn try_resize(&mut self, new_len: usize, value: T) -> MemResult<()> where T: Copy;
    pub fn pop(&mut self) -> Option<T>;
    pub fn remove(&mut self, index: usize) -> T;                     // panics if out of bounds
    pub fn swap_remove(&mut self, index: usize) -> T;                // panics if out of bounds
    pub fn truncate(&mut self, len: usize);
    pub fn clear(&mut self);
    pub fn shrink_to_fit(&mut self);                                 // best effort, never fails
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
    pub fn capacity(&self) -> usize;
    pub fn as_slice(&self) -> &[T];
    pub fn as_mut_slice(&mut self) -> &mut [T];

pub type KBytes = KVec<u8>;

/// UTF-8 text, for identifiers and messages. Shell data is KBytes, not KString.
pub struct KString { /* private */ }
impl KString {

    pub fn try_push_str(&mut self, text: &str) -> MemResult<()>;

    pub fn take_fmt_error(&mut self) -> Option<MemError>;

    pub fn clear(&mut self);
    pub fn iter(&self) -> impl Iterator<Item = (&K, &V)>;
    pub fn iter_mut(&mut self) -> impl Iterator<Item = (&K, &mut V)>;
```

`Borrow` relations provided so that byte and text keys can be looked up without allocating:
`KVec<T>: Borrow<[T]>`, `KString: Borrow<str>`.

### 5.7 What is deliberately absent

No `From`, `FromIterator`, `Extend`, `Clone`, `Default` or `ToOwned` implementation for the containers,
no `collect()` target, no infallible `push`: each would be an infallible growth path.

### 5.8 Transfer hook

```rust
/// Allocation hook of the canonical ABI, for the binding module (wired as a component export in L1b).
/// Semantics: `new_len == 0` returns a non-null pointer equal to `align` and allocates nothing;
/// `old_len == 0` allocates `new_len` bytes with alignment `align`;
/// otherwise reallocates the block (`old_ptr`, `old_len`, `align`) to `new_len`, preserving the first
/// `min(old_len, new_len)` bytes.
/// It never returns null: when the allocator refuses, it traps (`unreachable` on wasm, panic natively).
/// SAFETY: arguments follow the canonical ABI contract; `align` is a power of two.
pub unsafe fn cabi_realloc(old_ptr: *mut u8, old_len: usize, align: usize, new_len: usize) -> *mut u8;
/// Releases a block obtained from `cabi_realloc`. A zero length is a no-op.
/// SAFETY: (`ptr`, `len`, `align`) designate a live block from `cabi_realloc`.
pub unsafe fn transfer_free(ptr: *mut u8, len: usize, align: usize);
```

In this lot the hook is a function only; it is not exported from the wasm module and it performs no
headroom accounting (both come later). It is subject to the ceiling like any allocation.

## 6. Implementation constraints for this lot

- Bump allocator on wasm: grows linear memory with `core::arch::wasm32::memory_grow` in steps of at least
  one page, respects alignment, returns null when the ceiling refuses or the engine refuses to grow. It
  may ignore `dealloc`, except that freeing or reallocating the most recent block reuses its space.
  `used` and `high_water` nevertheless follow allocations and frees exactly as section 5.2 defines them
  (they count live bytes, not consumed address space).
- A `#[panic_handler]` for wasm that executes `unreachable`; no formatting of the panic message.
- `kernel/src/lib.rs` keeps `#![cfg_attr(target_arch = "wasm32", no_std)]`, declares `extern crate alloc`
  and `pub mod mem;`. The kernel still exports nothing.
- No use of `core::fmt` machinery that pulls panic formatting into the wasm build beyond what
  `core::fmt::Write` needs.
- Documentation comments on every public item, restating the failure behaviour.

## 8. Tests and exit gates

Native unit tests live next to the code (`#[cfg(test)]`) or under `kernel/tests/`. Tests that set the
ceiling use the test allocator described in 5.2; because the ceiling is process-wide, they run in one
test binary configured for serial execution, or reset the module state through a `#[cfg(test)]` helper.

Exit gates, all observable:

1. **Interface complete.** A test file `kernel/tests/interface.rs` names every public item of section 5
   with its full signature (function-pointer coercions or explicit calls), so that a signature change
   breaks compilation. Count: every `pub fn`, type, trait and macro listed in 5.1-5.8.
2. **Budget exactness.** For `KVec<u8>`, `KVec<u64>`, `KString`, `KBox<[u8; 64]>`, `KRc<[u8; 64]>` and
   `KMap<u32, u32>`: with a budget cap of exactly the bytes needed for N elements the operation succeeds,
   and with one byte less it returns `Limit(id)` with the budget's id and leaves length, capacity and
   `budget.used()` unchanged. N in {1, 4, 1 000}.
3. **Nested budgets.** A charge refused by a parent reports the parent's `LimitId`; after the refusal
   `used()` of child and parent are unchanged; a successful charge appears in both; `release` restores
   both to their previous values.
4. **Release on drop.** After dropping every container created in a test, `used()` of each budget is 0
   and `usage().used` is back to its value at the start of the test (0 byte leak), over a sequence of at
   least 10 000 mixed operations driven by a fixed-seed generator.
5. **Ceiling.** With the ceiling set to C, an allocation that would bring `usage().used` above C returns
   `Ceiling` and the container is unchanged; after `raise_ceiling(2 * C)` the same operation succeeds;
   `configure` twice returns `AlreadyConfigured`; `raise_ceiling` below the current value returns
   `BelowCurrent`; `high_water` never decreases.
6. **Overflow.** `with_capacity_in(usize::MAX, ..)` for a 16-byte element type and `try_reserve` that
   overflows return `Overflow`, without allocating.
7. **Value preservation.** `KBox::try_new_in` and `KRc::try_new_in` return the original value on
   failure; `KVec::try_push` and `KMap::try_insert` leave the container as it was.
8. **Semantics.** `KMap` iterates in ascending key order after 1 000 inserts and removals in pseudo-random
   order and agrees with a reference model kept in the test; `KRc` counts, `ptr_eq`, `get_mut` and
   `try_unwrap` behave as specified; `kbox_unsize!` yields a working `KBox<dyn Trait>` whose drop runs the
   concrete destructor exactly once and releases the budget.
9. **Formatting.** `write!` into a `KString` produces the expected text; with a budget too small it
   returns `fmt::Error`, `take_fmt_error()` yields the `Limit`, and the string holds no partial write
   beyond what fitted.
10. **Transfer hook.** `cabi_realloc` returns pointers aligned to 1, 2, 4 and 8; a zero-length request
    returns the alignment value; growing a block preserves its content; with the ceiling exhausted the
    native build panics (asserted with `should_panic`).
11. **Wasm build.** `make build` produces the kernel core module with zero imports (section 7.2); the
    PR states its size in bytes. `make check` prints G1 to G8 `OK`, with G6 passing on the real tree, and
    the existing G6 fixture test of L0 still failing its fixture.
12. **No stray unsafe.** A check (a node test under `test/`, or part of G6) fails if the word `unsafe`
    appears in `kernel/src/` outside `kernel/src/mem/` and the binding module path, and fails if an
    `unsafe` block in `kernel/src/mem/` is not preceded by a `// SAFETY:` comment.
13. `make check` is green on a clean worktree.
