## 4. Exact interfaces

### 4.1 L3 `syntax::Ast` touchpoints (`kernel/src/fiber/syntax/`)

1. **`WordPart::ArithExpand`** (`syntax/ast.rs` & `syntax/word.rs`):
   ```rust
   pub enum WordPart {
       // ... existing variants (Literal, SingleQuoted, AnsiCQuoted, DoubleQuoted,
       //     Escaped, ParamExpand, CommandSubst, ProcessSubst, BraceExpand,
       //     TildeExpand, Glob) unchanged ...
       ArithExpand { expr: ArithId, raw: Span },
   }
   ```
   `raw` stores the unexpanded inner bytes between `$((` and `))` (or `$[` and `]`) pushed into `Ast.bytes` at both `WordPart::ArithExpand` construction sites in `syntax/word.rs`. When `raw` contains an unbraced `$ident`, `$1`..`$9`, or special `$` parameter (`$*`, `$@`, `$#`, `$?`, `$-`, `$!`, `$$`) outside single quotes and outside `${...}` / `$(...)`, the evaluator performs text-level variable expansion (§5.6.2) and re-invokes `syntax::arith::parse_arith` against a scratch `Ast` before evaluating.
2. **Integer literal clamping in `syntax/arith.rs`**:
   `parse_base_digits` accumulates in `u128` or `f64` and clamps any valid literal whose value exceeds `crate::num::MAX_SAFE_INT` (`9_007_199_254_740_991`) to `BaseResult::Ok(crate::num::MAX_SAFE_INT as i64)`, producing `ArithExpr::Number(crate::num::MAX_SAFE_INT as i64)`. Invalid digits for the base (`08`, `2#102`, `42x`) still emit `ArithExpr::SyntaxError`. `ArithExpr::NumberOverflow` is no longer emitted by literal parsing.
3. **`ArithExpr::SingleQuote` and `$'...'` / `$"..."` in `syntax::arith::parse_dollar_piece`**:
   - Update `parse_primary_single_quote` (`'...'`) in `syntax/arith.rs` to parse the slice inside `'...'` as a signed base-10 integer prefix (matching JS `Number.parseInt(content, 10)`: skip leading ASCII whitespace, optional `+`/`-`, longest ASCII digit prefix, `0` when empty or non-numeric, clamped to `±(crate::num::MAX_SAFE_INT as i64)`), storing that `i64` in `ArithExpr::SingleQuote { content, value }`.
   - Extend `syntax::arith::parse_dollar_piece` (currently handling `((`, `[`, `(`, `{`, ident, and special vars) with two branches before the fallback error:
     - `Some(b'\'')` (`$'...'`): scan until unescaped `'`, decoding `\n`, `\t`, `\r`, `\\`, `\'`, and `\X -> X`, parse the decoded bytes as a signed base-10 integer prefix (`0` if empty or non-numeric, clamped to `±(crate::num::MAX_SAFE_INT as i64)`), and push `ArithExpr::Number(val)` (valid in both `(( ))` and `$(( ))`).
     - `Some(b'"')` (`$"..."`): scan until unescaped `"` (decoding `\X -> X`), parse the decoded bytes as a signed base-10 integer prefix (`0` if empty or non-numeric, clamped to `±(crate::num::MAX_SAFE_INT as i64)`), and push `ArithExpr::Number(val)`.
4. **Keep `CaseDir::Toggle` in `syntax/ast.rs` and `syntax/word.rs` (Owner Decision Q2):**
   L3 already parses `${var~[pat]}` and `${var~~[pat]}` into `ParamOp::CaseModification { direction: CaseDir::Toggle, all, pattern }`; leave those arms in `syntax/word.rs` intact.

`Vm` drives expansion through explicit state-machine frames (`VmFrame`) exposing five logical modes:
1. **`expand_words(word: WordId)` -> `ExpandedWords`**: full 7-stage pipeline (brace -> tilde -> parameter/arith/cmd/proc subst -> `IFS` split -> quote removal -> pathname globbing). Emits `bash:expansion:word_glob` once at entry. Used for `SimpleCmd` argument words (unless literal assignment builtin), `for` loop word lists, and unkeyed `a=(...)` array elements.
2. **`expand_scalar(word: WordId)` -> `KBytes`**: tilde + parameter + arithmetic + command/process substitution + quote removal; **no** brace expansion, **no** `IFS` word splitting, **no** pathname globbing, **no** `word_glob` coverage hit. Used for command-name single-word path when no split is needed, `case <word> in`, `<<<` here-strings, and `$(<file)` target path.
3. **`expand_assign_rhs(word: WordId, colon_tilde: bool)` -> `KBytes`**: same as `expand_scalar`, plus `:`-delimited tilde expansion (§5.3.3) when `colon_tilde` is true (`x=~/a:~/b`, `export x=~/a:~/b`, `${v:-~/a:~/b}` outside double quotes).
4. **`expand_redirect_target(word: WordId, raw_src: &[u8])` -> `RedirTarget`**: expands `word` without `word_glob` coverage hit; if `"$@"` with `$# >= 2`, brace expansion yielding `> 1` words, or unquoted `IFS` splitting yielding `> 1` words occurs, returns `RedirTarget::Error` with `"bash: <raw_src>: ambiguous redirect\n"` (`exit 1`). If `noglob` is off, `word` has no quoted parts or `ProcessSubst`, and the pattern has unquoted glob metacharacters, runs `GlobWalker`: `1` match -> `Path(match)`; `0` matches -> `Error("bash: no match: <val>\n", 1)` when `failglob` is on else `Path(unescaped_val)`; `>= 2` matches -> `Error("bash: <val>: ambiguous redirect\n", 1)`.
5. **`expand_pattern_word(word: WordId)` / `expand_regex_word(word: WordId)` -> `KBytes`**:
   - `expand_pattern_word` (for `case` and `[[ == ]]` / `[[ != ]]`): backslash-escapes `* ? [ ] ( ) | \` inside `SingleQuoted`, `AnsiCQuoted`, `DoubleQuoted`, and `Escaped` parts while leaving unquoted `Glob`, `Literal`, and unquoted expansion parts as active pattern metacharacters.
   - `expand_regex_word` (for `[[ =~ ]]`): backslash-escapes regex metacharacters (`\ ^ $ . * + ? ( ) [ ] { } |`) **only** in `WordPart::Escaped` and `WordPart::TildeExpand` outputs, while leaving `SingleQuoted`, `AnsiCQuoted`, `DoubleQuoted`, `Literal`, and parameter/command/arithmetic expansion outputs **unescaped** (matching `3.6.0`).

## 5. Complete behavioural specification

### 5.1 Expansion order and context matrix

For full word expansion (`expand_words`), stages execute in strict order:
1. Emit `bash:expansion:word_glob` on `Fiber::hit_coverage`.
2. **Brace expansion** (§5.2) over unquoted `WordPart::BraceExpand` nodes, producing `1..=N` candidate word-part sequences. Each generated branch independently evaluates later stages so side effects (`$((i++))`, `${v:=x}`, `$(cmd)`) run once per generated branch left-to-right.
3. **Tilde expansion** (§5.3) on leading unquoted `WordPart::TildeExpand` (and post-brace leading unquoted `~` strings such as `{~,~/sub}`).
4. **Parameter expansion** (§5.4–§5.5), **arithmetic expansion** (§5.6), **command substitution** (§5.7.1), and **process substitution** (§5.7.2), left-to-right across parts.
5. **`IFS` word splitting** (§5.8) on unquoted expansion outputs when `IFS` is unset or non-empty.
6. **Quote removal** (§5.8.4) and empty-word elision (an unquoted expansion producing `""` with no adjacent quoted part drops the word; `""` or `''` preserves an empty word).
7. **Pathname expansion** (§5.9) on each resulting word if `!ShellOpts.noglob`, `!quoted`, and the word contains at least one unquoted glob metacharacter (`*`, `?`, balanced `[...]`, or `?(...)`/`*(...)`/`+(...)`/`@(...)`/`!(...)` when `ShoptOpts.extglob` is enabled).

**Literal assignment-builtin rule (`SimpleCmd`):** When `SimpleCmd.name` is a *literal* unquoted word (only `WordPart::Literal`, no `$`, `` ` ``, quotes, or escapes) matching `"local"`, `"declare"`, `"typeset"`, `"export"`, or `"readonly"`:
- Any argument matching `ident=(...)` or `ident+=(...)` expands as a local/builtin array assignment without splitting or globbing.
- Any argument matching `ident=rhs`, `ident+=rhs`, `ident[sub]=rhs`, or `ident[sub]+=rhs` expands `rhs` via `expand_assign_rhs(..., colon_tilde: true)` without `IFS` splitting or pathname globbing (nor `word_glob` coverage hit).
- Other flag/name arguments (`-a`, `foo`) expand via `expand_words`.
- If the builtin name came from an expansion (`e=export; $e var=$x`), normal `expand_words` applies to all arguments (`var=$x` splits on `IFS` and globs).

**Empty command-name rule (`SimpleCmd`):**
- If `SimpleCmd.name` consists *solely* of `ParamExpand`, `CommandSubst`, and/or `ArithExpand` parts (unquoted) and expands to `0` words (or `""` dropped by splitting):
  - If expanded arguments exist, shift `args[0]` into `commandName` and run it.
  - If `args` is empty, execute redirections, persist prefix assignments, and finish with `exit = last_subst_exit_code.unwrap_or(0)` (`$(exit 42)` alone exits `42`; `$unset` alone exits `0`).
- If `SimpleCmd.name` had quotes (`""` or `''`) and expands to `""`, fail with `stderr = "bash: : command not found\n"`, `exit = 127`.

### 5.2 Brace expansion

A `WordPart::BraceExpand(Span)` holds `BraceItem` entries (`BraceItem::Word(WordId)` or `BraceItem::Range { start_num, end_num, start_char, end_char, step, raw }`):
1. **Comma lists (`{a,b,c}`):** Expand Cartesian product left-to-right across multiple brace groups in the same word (`{a,b}{1,2}` -> `a1`, `a2`, `b1`, `b2`) and iteratively inside nested `BraceItem::Word` items (`{a,{b,c}}` -> `a`, `b`, `c`).
2. **Integer sequence (`{start..end}` or `{start..end..step}`):**
   - Valid when `start_num` and `end_num` are `Some` (`start_str` and `end_str` are sliced from `ast.bytes(raw)` between `{`, the first `..`, and the optional second `..` / closing `}`).
   - Step magnitude and direction: let `mag = match step { None | Some(0) => 1, Some(s) => s.unsigned_abs() as i128 }`; step by `+mag` when `start <= end` and `-mag` when `start > end`. Thus `{5..1..2}` and `{5..1..-2}` both step by `-2` (`5 3 1`).
   - **Zero-padding (`3.6.0` digit-width rule):** For a bound slice `s`, let `digits = s.strip_prefix(b"-").unwrap_or(s)`. Let `bound_pad(s)` be `digits.len()` when `digits.len() >= 2 && digits[0] == b'0'` (i.e. `s` matches `^-?0[0-9]+$`), else `0`. Let `pad_width = bound_pad(start_str).max(bound_pad(end_str))` (check `pad_width <= maxStringLength` prospectively -> `Fail::StringLength`). When `pad_width > 0`, format `|n|` in base 10 zero-padded on the left to `pad_width` digits, then prepend `"-"` when `n < 0`! Thus `{01..04}` -> `01 02 03 04`, `{-01..-03}` -> `-01 -02 -03`, and mixed-sign `{-01..03}` pads to `2` digits -> `-01 00 01 02 03` (never `003` or `width - 1`).
3. **ASCII letter sequence (`{a..z}` or `{a..z..step}`):**
   - Valid when `start_char` and `end_char` are `Some` (single ASCII letters `[a-zA-Z]`).
   - **Cross-case check:** If `start.is_ascii_lowercase() != end.is_ascii_lowercase()` (e.g. `{z..A}` or `{A..z}`), fail the current command with recoverable `Fail::BraceSeq` -> `stderr = "bash: {<raw_inner>}: invalid sequence\n"`, `exit = 1` (script continues to next statement).
   - Otherwise step by `±|step|` (`1` when `step` omitted or `0`) from `start as u8` toward `end as u8`.
   - Note: if `{x..y}` was not a valid integer or single-letter sequence at lex/parse time (`{1..a}`), L3 kept it as `WordPart::Literal`, emitting `{1..a}` literally.
4. **Caps:**
   - Track cumulative brace expansion operations/results per word against `maxBraceExpansionResults` (`100_000` normal/contain, `10_000` hardened/micro). Exceeding `maxBraceExpansionResults` fails immediately with `Fail::BraceLimit` (`exit 126`, `limit_name = "maxBraceExpansionResults"`, `stderr = "bash: brace expansion: brace_operations work limit exceeded (<cap>)\n"`).
   - Every generated word checks cumulative string bytes against `maxStringLength` (`exit 126`, `limit_name = "maxStringLength"`).
5. **Keyed array element suppression:** Inside `a=([k]={x,y})`, `WordPart::BraceExpand` in the value portion of a `[key]=value` or `[key]+=value` array element is reconstructed literally as `"{x,y}"` (no brace expansion).

### 5.3 Tilde expansion

1. **Unquoted `WordPart::TildeExpand { user }`** (when `!in_double_quotes`):
   - Emit `bash:expansion:tilde`.
   - `user == None` (`~` or `~/...`): expand to `env.get(b"HOME")` if `HOME` is set (even if `HOME=""`), or `b"/home/user"` when `HOME` is unset.
   - `user == Some(u)` with `u == b"root"` (`~root` or `~root/...`): expand to `b"/root"`.
   - Any other `user` (`~alice`): remain literal `b"~alice"`.
   - Inside double quotes, `WordPart::TildeExpand` never hits coverage and yields literal `"~"` / `"~<user>"`.
2. **Post-brace tilde:** When brace expansion produces a branch starting with `"~"` from unquoted parts (e.g. `echo {~,~/q}` or `~{/src,root}`), `apply_tilde_expansion` runs on each branch's result: if it starts with `"~"`, emit `bash:expansion:tilde`, and expand `~` / `~/...` via `HOME ?? "/home/user"` and `~root` / `~root/...` to `"/root"`.
3. **Colon-separated assignment tilde (`expand_assign_rhs` with `colon_tilde = true`):**
   - On scalar assignment RHS (`x=~/a:~/b`, `x=~root/bin:$PATH`, `declare`/`export`/`local`/`readonly` `k=v` args, and keyed `[k]=~/a:~/b` literal array elements) and unquoted parameter default/assign/alternative operands (`${v:-~/a:~/b}` when the enclosing `${...}` is *not* inside double quotes): split unquoted literal `:` segments and apply tilde expansion at the start of the RHS and immediately after every unquoted literal `:`.
   - **Coverage rule (`3.6.0` parity):** Every `:`-split segment whose unquoted text starts with `~` (whether at index `0` via `WordPart::TildeExpand` or after an unquoted `:` inside `WordPart::Literal`, including `~unknown` which stays literal) emits **one** `bash:expansion:tilde` hit (never double-hitting segment `0`). Thus `p=~/a:~/b:~root/c` emits `bash:expansion:tilde` **3** times.

#### 5.4.2 Emptiness & unset predicate (`compute_is_empty`)
For `:-`, `:=`, `:?`, `:+` (`check_empty = true`) vs `-`, `=`, `?`, `+` (`check_empty = false`):
- `is_unset`:
  - Scalar `v`: `!env.contains(v) && !arrays.contains(v)` (note: an array `a=(1 2)` referenced as `${a}` acts like `${a[0]}`, so `is_unset` is `!has_element(a, 0)`!).
  - Array element `a[idx]`: `!has_element(a, idx)`.
  - `a[@]` or `a[*]`: `elements(a).is_empty() && !env.contains(a)`.
  - Positional `k >= 1`: `k > params.len()`.
  - `@` or `*`: `params.is_empty()`.
- `is_empty` (consulted when `check_empty == true`):
  - `*`: `params.is_empty()`.
  - `@`: `params.is_empty() || (params.len() == 1 && params[0].is_empty())`.
  - `a[*]`: if `elements(a).is_empty()` -> `true`; else if `in_double_quotes` -> `joined_with_ifs_sep.is_empty()`; else -> `false`.
  - `a[@]`: `elements(a).is_empty() || (elements(a).len() == 1 && elements(a)[0].val.is_empty())`.
  - Any other parameter: `value.is_empty()`.

#### 5.4.3 Default, AssignDefault, ErrorIfUnset, UseAlternative
1. **`DefaultValue` (`${p:-w}` / `${p-w}`):** Hit `bash:expansion:default_value`. If `is_unset || (check_empty && is_empty)`, expand `w` (preserving `in_double_quotes`; if outside double quotes and inside `expand_words`, `w` participates in word splitting/tilde); otherwise return `p`'s value(s).
2. **`AssignDefault` (`${p:=w}` / `${p=w}`):** Hit `bash:expansion:assign_default`. If `is_unset || (check_empty && is_empty)`:
   - If `p` is a positional or special parameter (`0`, `1`..`N`, `@`, `*`, `#`, `?`, `$`, `!`, `-`), fail fatally with `Fail::ParamExit`: `stderr = "bash: $<p>: cannot assign in this way\n"`, `exit = 1`.
   - If `p` is `a[@]` or `a[*]`, fail fatally with `Fail::ParamExit`: `stderr = "<expansion_stderr>bash: <p>: bad array subscript\n"`, `exit = 1`.
   - Expand `w` as scalar (`colon_tilde = !in_double_quotes`), assign to scalar `p` or array element `a[idx]` (checking `readonly` and `maxArrayElements`/`maxStringLength`), and return the assigned value.
3. **`ErrorIfUnset` (`${p:?w}` / `${p?w}`):** Hit `bash:expansion:error_if_unset`. If `is_unset || (check_empty && is_empty)`:
   - If `word` is `None` (`${p?}` or `${p:?}`), let `msg = "<p>: parameter null or not set"`; otherwise let `msg` be the expanded operand word (`${p:?custom}` -> `"custom"`).
   - Fail fatally with `Fail::ParamExit`: `stderr = "bash: <msg>\n"`, `exit = 1` (aborts script/subshell, preserving all coverage hits emitted prior to abort).
4. **`UseAlternative` (`${p:+w}` / `${p+w}`):** Hit `bash:expansion:use_alternative`. If `!(is_unset || (check_empty && is_empty))`, expand `w`; else return `""`.

#### 5.4.4 Length (`${#p}`) and `LengthSliceError`
- `${#p:...}` (`ParamOp::LengthSliceError`): fail fatally with `Fail::BadSubstitution(p)` -> `stderr = "bash: <p>: bad substitution\n"`, `exit = 1`.
- Otherwise hit `bash:expansion:length`:
  - `${#@}` or `${#*}`: decimal `params.len()`.
  - `${#arr[@]}` or `${#arr[*]}`: if `arr` is in `ArrayStore` with `> 0` elements, decimal `elements(arr).len()` (without joining element bytes, so huge arrays never trip `maxStringLength` on `${#arr[@]}`); else if scalar `arr` is set in `env`, `"1"`; else `"0"`.
  - Bare array name `${#arr}` when `arr` is in `ArrayStore`: Unicode scalar count of element `0` (`""` -> `"0"`).
  - Any other parameter: count **Unicode scalar values** (`utf8_chunks`, counting each valid `char` as 1 and each invalid isolated byte as 1) of `value`, formatted in base 10.

#### 5.4.5 Substring / Slicing (`${p:offset}` and `${p:offset:length}`)
1. **Associative array rejection:** If `p` is `A[@]` or `A[*]` and `A` is an associative array (`ShellArray::Assoc`), fail fatally with `Fail::ParamExit`: `stderr = "bash: ${<A>[@]: 0: 3}: bad substitution\n"`, `exit = 1` (exact literal `0: 3` string in `3.6.0`).
2. **Indexed array slicing (`${arr[@]:off[:len]}` / `${arr[*]:off[:len]}`):**
   - Standalone `"${arr[@]:off[:len]}"` / `"${arr[*]:off[:len]}"` runs the array-slice handler (no `bash:expansion:substring` hit), whereas scalar/composite `${arr[*]:off[:len]}` runs `handle_substring` (hits `bash:expansion:substring`).
   - Evaluate `offset` via `eval_arith` (empty -> `0`), truncated to `i64`; if `length` is `Some(l)`, evaluate via `eval_arith`.
   - **Negative length error (indexed arrays only):** If `length` is `Some(l)` with `l < 0`, fail command-recoverably with `Fail::Arith`: `stderr = "bash: <arr>[@]: substring expression < 0\n"`, `exit = 1`.
   - Sparse index resolution on `elements` (sorted ascending by `(idx, val)`, checked against `maxArrayElements`):
     - If `offset >= 0`: `start_pos` is the position of the first element with `idx >= offset as u64` (or `elements.len()` if none).
     - If `offset < 0`: if `elements.is_empty()`, result is `[]`; else let `max_idx = elements.last().0 as i64`, `target = max_idx + 1 + offset`. If `target < 0`, result is `[]`; else `start_pos` is the first element with `idx as i64 >= target` (or `elements.len()` if none).
   - Take `elements[start_pos .. (start_pos + len).min(elements.len())]` (or `elements[start_pos..]` when `length.is_none()`).
   - For `@` in word-producing context: return each sliced value as a separate word (`[]` if empty). For `*`: join sliced values with `IFS_SEP` into 1 word (`[]` if empty).
3. **Positional slicing (`${@:off[:len]}` / `${*:off[:len]}`):**
   - Let `all = params[0..N]` (`$1..$N`) and `shell_name = env("0") ?? "bash"`.
   - If `offset <= 0`: form `with_zero = [shell_name, ..all]`; `comp = with_zero.len() as i64 + offset`. If `comp < 0`, slice is `[]`; else `start = if offset < 0 { comp as usize } else { 0 }`, `end = match len { None => with_zero.len(), Some(l) if l < 0 => (with_zero.len() as i64 + l).max(start as i64) as usize, Some(l) => (start + l as usize).min(with_zero.len()) }`; take `with_zero[start..end]`.
   - If `offset > 0`: `start = (offset - 1) as usize`. If `start >= all.len()`, slice is `[]`; else `end = match len { None => all.len(), Some(l) if l < 0 => (all.len() as i64 + l).max(start as i64) as usize, Some(l) => (start + l as usize).min(all.len()) }`; take `all[start..end]`.
   - Prefix/suffix parts before/after `${@:...}` attach to the first and last sliced word respectively (`*` joins with `IFS_SEP`).
4. **Scalar string substring (`${v:off[:len]}` — `3.6.0` clamping rule):**
   - Emit `bash:expansion:substring`.
   - Operate on **Unicode scalar indices** (`chars`), `char_len = chars.count() as i64`.
   - Evaluate `offset` (`i64`): `start = if offset < 0 { (char_len + offset).max(0) as usize } else { (offset as usize).min(char_len as usize) }`.
   - Evaluate `length`:
     - `None` -> `chars[start..]`.
     - `Some(l)` with `l >= 0` -> `chars[start .. (start + l as usize).min(char_len as usize)]`.
     - `Some(l)` with `l < 0` -> `end = (char_len + l).max(start as i64) as usize`; return `chars[start..end]` with **exit `0`** (never raises `substring expression < 0` on scalars — e.g. `s='abcdef'; ${s:4:-4}` yields `""` with `exit 0`, matching `3.6.0`).

#### 5.4.6 Pattern removal (`#`, `##`, `%`, `%%`)
- For scalar `${v#pat}` / `${v##pat}` / `${v%pat}` / `${v%%pat}`: emit `bash:expansion:pattern_removal` (vectorized standalone `"${arr[@]#pat}"`, unquoted `${arr[@]#pat}`, and positional `${@#pat}` apply removal per element without hitting `bash:expansion:pattern_removal`, matching `3.6.0`).
- Build a glob pattern byte buffer sequentially from `pattern` parts:
  - `Glob`, `Literal`, and unquoted `ParamExpand` outputs contribute unescaped glob metacharacters;
  - `SingleQuoted`, `AnsiCQuoted`, `Escaped`, `DoubleQuoted`, `CommandSubst`, and `ArithExpand` outputs have `* ? [ ] \ ( ) |` backslash-escaped so they match literally.
- Call `kernel::glob::strip_prefix(value, &pat, greedy, GlobOptions { extglob: shopt.extglob, nocase: false, pathname: false, dotglob: true, max_extglob_depth }, budget, &mut work)` (or `strip_suffix` for `%`/`%%`), where `work` charges both `glob_ops` (`<= maxGlobOperations`, `Fail::GlobLimit`) and `Fiber::charge_work`:
  - Prefix `#` (`greedy = false`) strips shortest matching prefix `value[..end]`; `##` (`greedy = true`) strips longest `value[..end]`.
  - Suffix `%` (`greedy = false`) strips shortest matching suffix `value[start..]`; `%%` (`greedy = true`) strips longest `value[start..]`.
  - Check remaining slice length against `maxStringLength` (`Fail::StringLength`).
- Vectorized array/positional forms apply the same strip to every element of `arr[@]`/`arr[*]`/`@`/`*`.

#### 5.4.7 Pattern replacement (`/`, `//`, `/#`, `/%`)
- For scalar `${v/pat/rep}` / `${v//pat/rep}` / `${v/#pat/rep}` / `${v/%pat/rep}`: emit `bash:expansion:pattern_replacement` (vectorized array/positional handlers apply per element without hitting `pattern_replacement`, matching `3.6.0`).
- Expand `pattern` with the same literal-vs-glob escaping rules as §5.4.6, and expand `replacement` (`None` -> `b""`) as literal replacement text (`&` and `\1` are plain literal bytes, never backreferences).
- Empty-pattern anchor special cases (handled before calling `replace_glob`, because `replace_glob` returns empty on `subject == b""`):
  - `${v/#/rep}` (`anchor == Some(ReplaceAnchor::Start)` and `pat.is_empty()`): prepend `rep` to `value` (even when `value` is `""`, `${empty/#/pre}` -> `"pre"`), checking `maxStringLength`.
  - `${v/%/rep}` (`anchor == Some(ReplaceAnchor::End)` and `pat.is_empty()`): append `rep` to `value` (even when `value` is `""`, `${empty/%/suf}` -> `"suf"`), checking `maxStringLength`.
  - Unanchored empty pattern (`pat.is_empty()` and `anchor == None`): returns `value` unchanged.
- Map `(all, anchor)` to `GlobReplaceMode`:
  - `(true, _)` -> `GlobReplaceMode::All`
  - `(false, Some(ReplaceAnchor::Start))` -> `GlobReplaceMode::AnchorHead`
  - `(false, Some(ReplaceAnchor::End))` -> `GlobReplaceMode::AnchorTail`
  - `(false, None)` -> `GlobReplaceMode::First`
- Call `kernel::glob::replace_glob(value, &pat, &rep, mode, GlobOptions { extglob: shopt.extglob, nocase: false, pathname: false, dotglob: true, max_extglob_depth }, budget, &mut work)`:
  - Charge `work` against `maxGlobOperations` (`Fail::GlobLimit` -> `exit 126`) and `Fiber::charge_work`.
  - Check `out.len() <= maxStringLength` (`Fail::StringLength` -> `exit 126`).
  - `replace_glob` already implements `ShellExpansion` zero-length advancement (`x=abc; ${x//*/X}` -> `"X"`, not `"XX"`).

#### 5.4.8 Case modification (`^`, `^^`, `,`, `,,`, and `~`, `~~` — Owner Decision Q2 / `V12`)
- For scalar/composite `${p...}`: emit `bash:expansion:case_modification` (vectorized standalone/unquoted `${arr[@]...}` and `${@...}` transform element-wise).
- Optional `pattern`: if `None`, every inspected character matches; if `Some(w)`, expand `w` (using the §5.4.6 literal-vs-glob escaping rules) and compile once with `CompiledGlob::compile(&pat, GlobOptions { extglob: shopt.extglob, nocase: false, pathname: false, dotglob: true, max_extglob_depth }, budget)`. On `Err(GlobError::InvalidCharacterRange | GlobError::ExtglobDepthExceeded { .. })`, no character matches (returns `value` unchanged, V10).
- Direction transform `transform(c, direction)` on a Unicode scalar `c`:
  - `CaseDir::Upper` (`^`, `^^`): `c.to_uppercase()`.
  - `CaseDir::Lower` (`,`, `,,`): `c.to_lowercase()`.
  - `CaseDir::Toggle` (`~`, `~~`, **Owner Decision Q2 / `V12`**): if `c.is_uppercase()`, `c.to_lowercase()`; else if `c.is_lowercase()`, `c.to_uppercase()`; else `c` unchanged.
- When `all == false` (`^`, `,`, `~`):
  - For `CaseDir::Toggle` (`~`) and when `pattern` is `None`: inspect **only the first** Unicode scalar of `value` (if non-empty) and transform it if it matches `pattern`.
  - Note `3.6.0` `^` / `,` with `Some(pattern)`: scan Unicode scalars left-to-right and transform at most the first scalar matching `pattern` (`converted = true`).
- When `all == true` (`^^`, `,,`, `~~`): inspect every Unicode scalar of `value`, transforming each scalar for which `compiled.is_match(utf8_char, budget, &mut work)` is `true`.
- Enforce `maxStringLength` on the resulting byte buffer.

#### 5.4.9 `@` Transformations (`@Q`, `@E`, `@P`, `@A`, `@K`, `@k`, `@a`, `@u`, `@U`, `@L`)
- Scalar / composite `${p@op}` emits `bash:expansion:transform` (standalone `"${arr[@]@op}"` / `"${arr[*]@op}"` runs the array transform handler without hitting `transform`, matching `3.6.0`).
- **`quote_value(s)` helper** (`3.6.0` exact escaping, used by `@Q`, `@A`, and scalar `@K`/`@k`):
  - If `s` is empty (`b""`): return `"''"`.
  - If `s` contains **any** single quote `'` (`0x27`) **or** any control byte (`0x00..=0x1f` or `0x7f`): format as ANSI-C `$'...'`, iterating UTF-8 scalars (with isolated invalid bytes `< 0x80` impossible and `>= 0x80` preserved literally):
    - `'` (`0x27`) -> `\'`
    - `\` (`0x5c`) -> `\\`
    - `\n` (`0x0a`) -> `\n`
    - `\r` (`0x0d`) -> `\r`
    - `\t` (`0x09`) -> `\t`
    - Any other control byte (`< 0x20` or `== 0x7f`) -> `\` followed by 3 zero-padded octal digits (`\007`, `\033`, `\177`; **never** `\a`, `\b`, `\e`, `\f`, `\v`, or `\xHH`).
    - All other printable ASCII bytes (`0x20..=0x7e`) and all non-ASCII UTF-8 bytes (`>= 0x80`) are emitted **literally** inside `$'...'` (`x="a'b"` -> `$'a\'b'`; `y=$'é\n'` -> `$'é\n'`).
  - Otherwise (no `'` and no control byte `< 0x20` or `0x7f`): wrap in single quotes `'...'` (`'value'`).
- **`quote_kv_key(k)` and `quote_kv_value(v)` helpers** (GNU bash `assoc_to_kvpair` / `array_to_kvpair` rules for array `@K`, **Owner Decision Q4 / `V14`**):
  - `sh_double_quote(s)`: wrap `s` in `"..."`, backslash-escaping **only** `"` (`\"`), `\` (`\\`), `$` (`\$`), and `` ` `` (`` \` ``) (`""` -> `""`, i.e. two double-quote bytes `b"\"\""`).
  - `ansic_quote_bash(s)` (used when `s` contains any control byte `0x00..=0x1f` or `0x7f`): wrap in `$'...'`, escaping `'` (`\'`), `\` (`\\`), `0x07` (`\a`), `0x08` (`\b`), `0x1b` (`\E`), `0x0c` (`\f`), `0x0a` (`\n`), `0x0d` (`\r`), `0x09` (`\t`), `0x0b` (`\v`), and any other byte `< 0x20` or `0x7f` as 3-digit octal `\NNN`, leaving printable ASCII and UTF-8 bytes literal.
  - `quote_kv_value(v)`: if `v` contains any control byte (`0x00..=0x1f` or `0x7f`), `ansic_quote_bash(v)`; else `sh_double_quote(v)`.
  - `quote_kv_key(k)`: for `ShellArray::Indexed`, unquoted decimal index (`0`, `1`, `5`); for `ShellArray::Assoc`, if `k` contains any control byte (`0x00..=0x1f` or `0x7f`), `ansic_quote_bash(k)`; else if `k.is_empty()` or `k == b"@"` or `k` contains any shell metacharacter / whitespace (`' '`, `'\t'`, `'\n'`, `'|'`, `'&'`, `';'`, `'('`, `')'`, `'<'`, `'>'`, `'\''`, `'"'`, `'\\'`, `'$'`, `` '`' ``, `'*'`, `'?'`, `'['`, `']'`, `'#'`, `'~'`, `'='`, `'%'`, `'{'`, `'}'`), `sh_double_quote(k)`; else bare `k` (`k1` -> `k1`, `k 2` -> `"k 2"`).
- Per-operator behaviour:
  - **`@Q`**: if `is_unset`, `""`; if `p` is `arr[@]`/`arr[*]` in scalar context, `quote_value` each element joined by `" "` (in standalone `"${arr[@]@Q}"`, one quoted word per element, `[]` if unset/empty; `"${arr[*]@Q}"`, joined by `IFS_SEP`, `[""]` if unset); else `quote_value(value)`.
  - **`@E`**: interpret backslash escapes `\a` (`0x07`), `\b` (`0x08`), `\e` (`0x1b`), `\f` (`0x0c`), `\n` (`0x0a`), `\r` (`0x0d`), `\t` (`0x09`), `\v` (`0x0b`), `\\`, `\'`, `\"`, `\?` in `value` (leaving unrecognized `\x` intact). In standalone `"${arr[@]@E}"` / `"${arr[*]@E}"`, leave elements **untransformed** (raw element values, matching `3.6.0`).
  - **`@P`**: prompt-string escape expansion on `value` (enforcing `maxStringLength` -> `Fail::StringLength`, `exit 126`):
    - `\a` -> `0x07`, `\e` -> `0x1b`, `\n` -> `\n`, `\r` -> `\r`, `\\` -> `\`, `\$` -> `"$"` (always `"$"`), `\[` -> `""`, `\]` -> `""`, trailing `\` -> `"\\"`, `\x` -> `"\\x"`, any other unrecognized `\c` -> `"\\<c>"`.
    - `\u` -> non-empty `env("USER")`, else non-empty `env("LOGNAME")`, else `"user"`.
    - `\H` -> non-empty `env("HOSTNAME")`, else `"localhost"`; `\h` -> prefix of `\H` before the first `.`.
    - `\w` -> let `pwd = non_empty(env("PWD")) ?? "/"`, `home = non_empty(env("HOME")) ?? "/"`; if `pwd.starts_with(home)`, `"~" + &pwd[home.len()..]` else `pwd`. `\W` -> last `/`-split segment of `pwd` if non-empty, else `pwd` (`"/"` stays `"/"`).
    - `\s` -> `"bash"`, `\v` -> `"5.0"`, `\V` -> `"5.0.0"`, `\j` -> `"0"`, `\l` -> `"tty"`, `\!` and `\#` -> non-empty `env("__COMMAND_NUMBER") ?? "1"`.
    - `\NNN` (1–3 octal digits `[0-7]`) -> code unit `(val & 0xff)` encoded as UTF-8 (`0x00..=0x7f` single byte, `0x80..=0xff` `char::from(code)`).
    - **Clock escapes (`\d`, `\t`, `\T`, `\@`, `\A`, `\D{fmt}`) — Owner Decision Q1 (`V11`, class `sandbox`, EVOL D9 / S11):**
      - When `!Shell::granted(G_REAL_CLOCK)` (default): **never** emit `HostReq::Clock`; read `epoch_sec = (Shell.virt_ms.get() / 1000) as i64` synchronously (`0` initially).
      - When `Shell::granted(G_REAL_CLOCK)` is `true` and `value` contains a clock escape: emit `HostReq::Clock` (`Pending::ExpandClock`). On `Outcome::Clock { wall_ms, .. }`, optionally sync `Shell.virt_ms` (when `wall_ms >= 0`) and use `epoch_sec = wall_ms.div_euclid(1000)`; on `Outcome::Denied` (host provides no real-clock handler), fall back to `(Shell.virt_ms.get() / 1000) as i64`.
      - Format through `kernel::format::format_strftime(fmt_bytes, epoch_sec, env.get(b"TZ"), max_ops, rem_bytes, budget, &mut work)`:
        - `\d` -> `b"%a %b %e"` (**space-padded** day-of-month `%e`, e.g. `"Thu Jan  1"` at epoch `0` UTC);
        - `\t` -> `b"%H:%M:%S"`;
        - `\T` -> `b"%I:%M:%S"`;
        - `\@` -> `b"%I:%M %p"`;
        - `\A` -> `b"%H:%M"`;
        - `\D{fmt}` -> `b"%H:%M:%S"` when `fmt` is empty (`\D{}`), else `fmt` (unclosed `\D{abc` without `}` emits literal `"\\D"` and continues after `\D`).
  - **`@a`**: attribute letters of variable `base_name(p)` in exact order: **`a` (indexed array), `A` (assoc array), `i` (`INTEGER`), `n` (`NAMEREF`), `r` (`READONLY`), `x` (`EXPORTED`)** (`-l`/`LOWER` and `-u`/`UPPER` are **not** included in `@a`; non-identifier special parameters return `""`). In standalone `"${arr[@]@a}"`, emit the array's attribute string once per element (`[""]` if `arr` is a set scalar, `[]` if unset).
  - **`@A`**: if `is_unset`, `""`; else `"<p>=<quote_value(value)>"`. In standalone `"${arr[@]@A}"` / `"${arr[*]@A}"`, leave elements **untransformed** (raw element values, matching `3.6.0`).
  - **`@K` and `@k` (Owner Decision Q4 / `V14`, class `upstream-defect`, GNU bash semantics):**
    - **On a scalar** (`${s@K}`, `${s@k}`, `"${s@K}"`, `"${s@k}"`, array element `${a[0]@K}`, or set scalar `s` accessed as `${s[@]@K}` / `${s[@]@k}`): if `is_unset` -> `""` (or `[]` for `"${unset[@]@K}"` / `"${unset[@]@k}"`, `[""]` for `"${unset[*]@K}"` / `"${unset[*]@k}"`); otherwise behaves identically to `@Q`, returning `quote_value(value)`!
    - **On an indexed or associative array (`a[@]` or `a[*]` when `a` is in `ArrayStore`):** iterate entries in `ArrayStore` order (ascending `u64` index for `Indexed`, ascending lexicographic `[u8]` key for `Assoc`):
      - **`@K`**: if `elements` is empty, `"${a[@]@K}"` yields `0` words (`[]`), `"${a[*]@K}"` yields `[""]`, and unquoted/scalar yields `""`. Otherwise format each `(k, v)` pair as `"<quote_kv_key(k)> <quote_kv_value(v)>"` and join pairs with `" "` into a single string `S` (checking `maxStringLength`):
        - Standalone `"${a[@]@K}"` and `"${a[*]@K}"`: both yield **1 quoted word** `[S]`.
        - Scalar / composite context (`x=${a[@]@K}`, `"p${a[@]@K}s"`): yields `S` (hitting `bash:expansion:transform`).
        - Unquoted `${a[@]@K}` / `${a[*]@K}` in `expand_words`: splits `S` via `IFS` word splitting and pathname globs each resulting word.
      - **`@k`**: build the `2 * N`-word list `W = [k_0, v_0, k_1, v_1, ...]` of raw unquoted keys (decimal index bytes for `Indexed`, raw key bytes for `Assoc`) and raw unquoted values (checking `maxArrayElements` and cumulative `maxStringLength`):
        - Standalone `"${a[@]@k}"`: yields `W` as **`2 * N` separate quoted words** (`[]` when `a` is empty; `"pre${a[@]@k}suf"` attaches `pre` to `W[0]` and `suf` to `W[2*N - 1]`).
        - Standalone `"${a[*]@k}"`: joins `W` with `IFS_SEP` into **1 quoted word** (`[""]` when `a` is empty).
        - Unquoted `${a[@]@k}` / `${a[*]@k}` in `expand_words`: applies unquoted-array `IFS` splitting and pathname globbing over `W` (§5.5.3).
        - Scalar context (`x=${a[@]@k}`, `x=${a[*]@k}`): joins `W` with `" "` (`@`) or `IFS_SEP` (`*`), hitting `bash:expansion:transform`.
  - **`@u`**: uppercase first Unicode scalar of `value` (per element on arrays).
  - **`@U`**: uppercase all Unicode scalars of `value` (per element on arrays).
  - **`@L`**: lowercase all Unicode scalars of `value` (per element on arrays).

#### 5.4.10 Indirection (`${!ref}` and `${!ref op}`), ArrayKeys (`${!arr[@/*]}`), VarNamePrefix (`${!prefix*/@}`)
1. **Indirection (`ParamOp::Indirection { inner_op }`):**
   - If standalone `"${!ref}"` (or `"${!ref op}"`) where `ref`'s value matches `arr[@]`, `arr[*]`, `@`, or `*`: expand indirectly to the target array/positional elements (slicing/default/transform applied to target elements if `inner_op` is `Some`), without hitting `bash:expansion:indirection`.
   - Otherwise emit `bash:expansion:indirection`:
     - If `ref` has the `NAMEREF` (`declare -n`) attribute: return the nameref's target name string (`""` if unbound).
     - If `ref` is **unset**: if `inner_op` is `Some(UseAlternative)` (`${!unset:+alt}`), return `""`; otherwise fail command-recoverably with `Fail::IndirectUnset`: `stderr = "bash: ${!<ref>}: bad substitution\n"`, `exit = 1` (command fails, script continues!).
     - Let `target = value_of(ref)`. If `target` is `""` (i.e. `ref=""` is set to empty), return `""` (`exit 0`, unless `ref` was `arr[@]`/`arr[*]`, which fails with `Fail::IndirectUnset`). If `target` has a subscript containing `~`, fail with `Fail::IndirectUnset`.
     - Otherwise evaluate `target` (with `inner_op` if `Some`, or `get_variable(target)` if `None`).
2. **Array keys (`${!arr[@]}` and `${!arr[*]}`):**
   - Keys are ascending decimal indices (`"0"`, `"1"`, `"5"`) for `ShellArray::Indexed` and ascending lexicographic byte keys for `ShellArray::Assoc` (`[]` if `arr` is not an array or is empty).
   - Standalone `"${!arr[@]}"`: returns each key as a separate quoted word (`[]` if empty; no `array_keys` coverage hit).
   - Standalone `"${!arr[*]}"`: returns 1 quoted word joining keys with `IFS_SEP` (`[""]` if empty; no `array_keys` coverage hit).
   - Unquoted `${!arr[@]}` / `${!arr[*]}`: splits keys on `IFS` (`[]` if empty; no `array_keys` coverage hit).
   - Scalar or composite `"prefix${!arr[*]}"` / `x=${!arr[@]}`: emits `bash:expansion:array_keys`; joins keys with `IFS_SEP` (`*`) or `" "` (`@`). (Note `3.6.0` `nounset` quirk: in composite/scalar `expandParameterAsync`, `ArrayKeys` and `VarNamePrefix` have `parameter == ""`; under `set -u`, `3.6.0` checks `getVariable("", true)` which fails with `bash: : unbound variable\n`! Reproduce this exact check when `set -u` is active and `ArrayKeys`/`VarNamePrefix` goes through scalar/composite `expand_param`!)
3. **Variable name prefix (`${!prefix*}` and `${!prefix@}`):**
   - Collect the deduplicated union of all names in `Fiber.env` (valid identifiers) and `ArrayStore.arrays` starting with `prefix`, sorted in ascending UTF-8 byte order.
   - Standalone `"${!prefix@}"` -> separate quoted words; `"${!prefix*}"` -> 1 `IFS_SEP`-joined quoted word; unquoted `${!prefix@}` / `${!prefix*}` -> `IFS`-split words; scalar/composite -> emits `bash:expansion:var_name_prefix` and joins with `IFS_SEP` (`*`) or `" "` (`@`).

### 5.5 Arrays and associative arrays in assignments & expansion

1. **Namespaces & scalar/array equivalence:**
   - Assigning `a=(...)` clears any scalar `env[a]` and stores `ShellArray::Indexed` (unless `a` was declared `-A`, in which case `ShellArray::Assoc`).
   - Assigning scalar `a=val`: if `a` is already in `ArrayStore`, assign element `0` (`a[0]=val` for `Indexed`, `a["0"]=val` for `Assoc`); otherwise set scalar `env[a] = val`. Reading `${a}` when `a` is in `ArrayStore` reads element `0` (`""` if absent), and reading `${s[@]}` / `${s[*]}` / `${s[0]}` when `s` is a scalar in `env` treats `s` as a 1-element array `[s]` at index `0`.
   - Variable attribute transforms on assignment: if `a` has `INTEGER` (`declare -i`), evaluate RHS string via `eval_arith` (invalid expression -> `"0"`, valid -> `fmt_f64_js(res)`); if `LOWER` (`declare -l`), lowercase RHS; if `UPPER` (`declare -u`), uppercase RHS.
2. **Array literal assignment (`a=(w1 w2 ...)` and `a+=(w1 w2 ...)`):**
   - Snapshot existing `a` before mutating; if any limit (`maxArrayElements`, `maxStringLength`) or arithmetic error fires partway through, restore `a` to its snapshot before propagating!
   - `a=(...)` (`append == false`) clears existing elements of `a`; `a+=(...)` (`append == true`) appends starting at `max_existing_index + 1` (`0` if empty) for `Indexed`, or merges/appends keys for `Assoc`.
   - Each element word `w` is inspected for `[key]=val` / `[key]+=val`:
     - For `ShellArray::Assoc`: `key` expands parameter/command substitutions; `val` expands via `expand_assign_rhs` (`colon_tilde = true`, with braces kept literal!). Unkeyed pairs in `declare -A A=(k1 v1 k2 v2)` pair alternating words `(k, v)`.
     - For `ShellArray::Indexed`: `[expr]=val` evaluates `expr` via `eval_arith` to compute `current_idx` (subsequent unkeyed words continue at `current_idx + 1, current_idx + 2, ...`). Negative index `idx < 0` resolves relative to `max_index + 1 + idx`; if still `< 0` (or array is empty), fail with `stderr = "bash: line <L>: <a>[<sub>]: bad array subscript\n"` (or `"bash: <a>[<sub>]: bad array subscript\n"`), `exit = 1`. Unkeyed words expand via `expand_words` (full brace + split + glob!), appending each resulting word sequentially.
   - `a[0]=(1 2)` (list assigned to subscripted name) fails with `stderr = "bash: <a>[<sub>]: cannot assign list to array member\n"`, `exit = 1`.
   - `a[]=val` (empty subscript) fails with `stderr = "bash: <a>[]: bad array subscript\n"`, `exit = 1`.
   - Prefix array assignment with a command (`a=(1 2) cmd`) temporarily sets `env["a"] = "(1 2)"` for `cmd` and restores `a` afterward.
3. **Word-producing `"$@"` / `"$*"` / `"${arr[@]}"` / `"${arr[*]}"` vs unquoted:**
   - `"pre${arr[@]}suf"` (double-quoted `@`): if `arr` has elements `[e0, e1, ..., ek-1]`, yields `[pre+e0, e1, ..., ek-1+suf]`. If `arr` has `0` elements (and no scalar `arr`), yields `[pre+suf]` when `pre+suf` is non-empty, or **`0` words (`[]`)** when `pre` and `suf` are both empty (`"${empty_arr[@]}"` elides completely!). Same for `"pre$@suf"`.
   - `"pre${arr[*]}suf"` / `"pre$*suf"` (double-quoted `*`): always yields **1 quoted word** `pre + join(elements, IFS_SEP) + suf` (`""` when `0` elements and `pre`/`suf` empty).
   - Unquoted `$@`, `$*`, `${arr[@]}`, `${arr[*]}`:
     - `0` elements -> `0` words (or `IFS`-split `pre+suf` if non-empty).
     - `IFS == ""`: keep non-empty elements separate (filter out `""`), no splitting, then pathname glob each word.
     - Whitespace-only `IFS` (default `" \t\n"`): drop empty elements, split each non-empty element with `split_by_ifs`, then pathname glob each word.
     - Non-whitespace `IFS` (e.g. `IFS=:`): for `@` (and `$*` with prefix/suffix), preserve internal `""` elements, split non-empty elements on `IFS`, strip trailing `""` words, then pathname glob; for standalone unquoted `$*` / `${arr[*]}`, join with `IFS_SEP` then split on `IFS`, then pathname glob.

### 5.6 Arithmetic evaluation, `(( ))` & `for ((;;))`

1. **Numeric domain (EVOL D1 / P2 + Owner Decision Q3 / `V13`):**
   - Runtime arithmetic value is `f64`.
   - Addition `+`, subtraction `-`, multiplication `*`: IEEE-754 `f64` (`+`, `-`, `*`).
   - Division `/`: if `rhs == 0.0`, fail with `Fail::Arith("division by 0")` (`stderr = "bash: division by 0\n"` in `$((...))`, `"bash: arithmetic expression: division by 0\n"` in `((...))`, `exit = 1`). Otherwise `kernel::num::f64_trunc(lhs / rhs)` (normalized so `-0.0` becomes `+0.0`).
   - Remainder `%`: if `rhs == 0.0`, fail with `Fail::Arith("division by 0")`. Otherwise IEEE-754 `lhs % rhs` (`-7.0 % 2.0 == -1.0`, `7.0 % -2.0 == 1.0`, normalized `-0.0 -> +0.0`).
   - **Compound `/=` and `%=` on `0` (Owner Decision Q3 / `V13`, class `upstream-defect`, GNU bash semantics):** Evaluate the target variable/subscript and `rhs`; if `rhs == 0.0` (including `-0.0`), **do not modify the target variable or array element**, and fail with `Fail::Arith("division by 0")` with the exact same message, exit status (`1`, command-recoverable), and context formatting (`"bash: arithmetic expression: division by 0\n"` in `((...))` / `for ((;;))`, `"bash: division by 0\n"` in `$((...))` / `$[...]`) as binary `/` and `%`! When `rhs != 0.0`, assign `f64_trunc(cur / rhs)` for `/=` and `cur % rhs` for `%=` (normalized `-0.0 -> +0.0`).
   - Exponentiation `**` (right-associative): if `rhs < 0.0`, fail with `Fail::Arith("exponent less than 0")`. Otherwise `libm`-free `f64` integer/float power matching JS `lhs ** rhs` (exact binary exponentiation for integer exponents `rhs == f64_trunc(rhs)` in IEEE-754 `f64`, so `2 ** 70 == 1.1805916207174113e+21` matches V8 identically).
   - Bitwise `~`, `&`, `|`, `^`, `<<`, `>>` and compound `&=`, `|=`, `^=`, `<<=`, `>>=`: convert operands via **ECMA-262 `ToInt32`** (`fn to_i32_js(x: f64) -> i32`: if `!x.is_finite() || x == 0.0` -> `0`; else let `n = f64_trunc(x) % 4_294_967_296.0`, wrap into `[-2_147_483_648, 2_147_483_647]` as `i32`). Shift count uses `(to_i32_js(rhs) as u32) & 0x1f`; `<<` is `lhs_i32.wrapping_shl(cnt) as f64`; `>>` is arithmetic signed shift `(lhs_i32 >> cnt) as f64` (`1 << 31 == -2147483648`, `-1 >> 1 == -1`).
   - Comparisons `<`, `<=`, `>`, `>=`, `==`, `!=`: IEEE-754 `f64` comparison yielding `1.0` or `0.0`.
   - Logical `!`, `&&`, `||`, ternary `cond ? a : b`, comma `a, b`: truthiness is `val != 0.0 && !val.is_nan()`; `&&`, `||`, and `?:` short-circuit (never evaluating untaken branches or their side effects/assignments/errors).
   - **Formatting:** Convert final `f64` to string via `kernel::num::fmt_f64_js` / `f64_to_js_string` (`0.0` and `-0.0` -> `"0"`, `2.0**70` -> `"1.1805916207174113e+21"`).
2. **`$var` text pre-expansion in `$(( ... ))` / `$[ ... ]`:**
   - When `WordPart::ArithExpand.raw` contains an unbraced `$ident`, `$1`..`$9`, or `$[*@#?\-!$]` outside `'...'` and outside `${...}` / `$(...)`: substitute those `$` tokens with `get_variable` in a scratch buffer (honouring `set -u`!), strip unescaped `"..."` wrapper quotes (preserving backslash-escaped chars), re-parse via `syntax::arith::parse_arith`, and evaluate with `is_expansion_ctx = true`. Thus `x='1 + 2'; echo $(( $x * 3 )) $(( x * 3 ))` outputs `"7 9"`.
3. **Recursive variable indirection & cycle/depth caps:**
   - Evaluating bare identifier `v` in arithmetic: read `get_variable(v)` (under `set -u`, unset `v` raises `Fail::Nounset(v)` -> fatal `exit 1`!; without `set -u`, unset or whitespace-only `v` evaluates to `0.0`).
   - Trim ASCII whitespace; if empty -> `0.0`. Try signed decimal / `kernel::num::parse_arith_literal` (`Result<f64, ArithNumError>`): if exact integer literal -> `val`.
   - Otherwise `v`'s string is an arithmetic expression (e.g. `a=b`, `b='1 + 2'`): check `visited` list; if `v` is already in `visited`, fail with `Fail::Arith("arithmetic variable cycle detected at <v>")`. If `indirection_depth >= 100`, fail with `Fail::Arith("maximum variable indirection depth exceeded")`. Push `v` onto explicit indirection stack, parse `v`'s string with `parse_arith`, and evaluate it!
4. **Context-sensitive single quotes (`ArithExpr::SingleQuote`):**
   - When `is_expansion_ctx == true` (`$((...))` and `$[...]`): fail command-recoverably with `Fail::Arith`: `stderr = "bash: syntax error: operand expected (error token is \"'<content>'\")\n"`, `exit = 1`.
   - When `is_expansion_ctx == false` (`((...))` and `for ((;;))`): evaluate to `value as f64` (`(( x = '42' ))` sets `x=42`, exit `0`; `(( x = 'a' ))` sets `x=0`, exit `1`).
5. **Deferred syntax errors in arithmetic:**
   - `ArithExpr::NumberSubscript { number, error_token }` (`1[2]`): fail with `Fail::Arith("<number><error_token>: syntax error: invalid arithmetic operator (error token is \"<error_token>\")")`.
   - `ArithExpr::DoubleSubscript` (`a[1][1]`): fail with `Fail::Arith` (`double subscript` / `exit 1`).
   - `ArithExpr::SyntaxError { message, .. }`: fail with `Fail::Arith(message)`.
6. **`Command::Arithmetic` (`(( expr ))`):**
   - Emit `bash:cmd:ArithmeticCommand`. Update `Vm.current_line = line`. Apply redirections. Evaluate `expr` with `is_expansion_ctx = false`.
   - If evaluation succeeds: `last_exit = if val != 0.0 { 0 } else { 1 }`. Flush `expansion_stderr`.
   - If `Fail::Arith(msg)` occurs: write `"bash: arithmetic expression: <msg>\n"` to stderr, `last_exit = 1`, continue script (`Nounset` and `LimitExceeded` propagate as fatal/limit).
7. **`Command::CStyleFor` (`for (( init; cond; update )); do body; done`):**
   - Emit `bash:cmd:CStyleFor`. Update `Vm.current_line = line`.
   - Evaluate `init` if `Some` (`is_expansion_ctx = false`).
   - Increment `loop_depth`; maintain `iterations: u64 = 0`, `body_exit: i32 = 0`:
     - Each loop turn increments `iterations`; if `iterations > maxLoopIterations`, fail with `Fail::LoopLimit("for")` -> `exit = 126`, `limit_name = "maxLoopIterations"`, `stderr = "bash: for loop: too many iterations (<cap>), increase executionLimits.maxLoopIterations\n"`.
     - If `cond` is `Some`: set `Vm.current_line = line`, evaluate `cond`; if `cond == 0.0`, break loop with `last_exit = body_exit`.
     - Execute `body` statements, updating `body_exit = last_exit`.
     - On `break`: adopt `0` status, break (multi-level `break N` decrements `N` and propagates when `N > 1 && loop_depth > 1`).
     - On `continue`: adopt `0` status; **still evaluate `update` if `Some`** before next iteration!
     - After normal body completion: evaluate `update` if `Some`.

### 5.7 Command and process substitution hooks

#### 5.7.1 Command substitution (`$(...)`, `` `...` ``, and `$(<file)`)
1. **`$(<file)` direct file-read shorthand:**
   - Matches when `CommandSubst` (`backtick == false`) has an AST body consisting of **1** statement with **0** `&&`/`||` operators, **1** non-negated pipeline of **1** `Command::Simple`, whose `SimpleCmd` has `name == None`, `args.is_empty()`, `assigns.is_empty()`, and **1** redirection with `RedirOp::In` (`<`) and `RedirTarget::Word(target_word)`. (`$(<file; cmd)` does **not** match.)
   - Expand `target_word` via `expand_scalar`; resolve relative to `Fiber.cwd`.
   - Read file from `Vfs` (or via `Pending::ExpandFs` -> `HostReq::FsBatch` `ReadFile` when resolved on a host mount; lazy files trigger `HostReq::LazyFile`).
   - On success: strip all trailing `\n` (`0x0a`) bytes, check `result.len() <= maxStringLength` (`Fail::StringLength` -> `exit 126`), set `Vm.last_subst_exit = Some(0)`, and yield the bytes.
   - On missing/unreadable file (any FS error other than memory/limit): emit **nothing** to stderr, set `Vm.last_subst_exit = Some(1)`, and yield `b""`.
2. **General `$(...)` and `` `...` `` execution:**
   - Check `Vm.subst_depth >= maxSubstitutionDepth` (`50`). If exceeded, fail immediately with `Fail::SubstDepth { proc: false, cap }` (`exit 126`, `limit_name = "maxSubstitutionDepth"`, `stderr = "bash: Command substitution nesting limit exceeded (<cap>)\n"`).
   - Push an explicit `VmFrame::CmdSubst` saving `(env_clone, arrays_clone, shell_opts, shopt_opts, cwd_clone, bash_pid, subst_depth)` onto `Vm.frames`; set `subst_depth += 1`, `bash_pid = next_virtual_pid` (`next_virtual_pid += 1`), and redirect stdout capture into a bounded `KBytes` buffer while capturing stderr into `Vm.expansion_stderr`.
   - Run the sub-script statements through the normal resumable `Vm` loop!
   - If `exit N` runs inside `$(...)`, it terminates **only** the `CmdSubst` frame (recording `exit_code = N` and keeping stdout/stderr produced so far), **never** the outer script! By contrast, any `Status::LimitExceeded` (`126`) propagates all the way out and terminates the fiber.
   - On frame completion: restore `(env, arrays, shell_opts, shopt_opts, cwd, bash_pid, subst_depth)`, record `Vm.last_subst_exit = Some(exit_code)`, strip all trailing `\n` bytes from captured stdout, verify `output.len() <= maxStringLength` (`Fail::StringLength` -> `exit 126`), and splice `output` into the suspended expansion state!
   - **Exit code propagation (`last_subst_exit`):** Reset `Vm.last_subst_exit = None` at the start of each `SimpleCmd`. When a `SimpleCmd` has **no** command name (e.g. `x=$(false)` or `$(exit 42)`), `Fiber.last_exit` becomes `Vm.last_subst_exit.unwrap_or(0)`. When a real command runs (`echo $(false)`), `echo`'s own exit status (`0`) overwrites `Fiber.last_exit`.
   - **`expansion_stderr` delivery:** Bytes accumulated in `Vm.expansion_stderr` during expansion of a command's assignments and words are prepended to the command's stderr result *after* the outer command's own redirections are applied (so `echo $(echo err >&2) >/dev/null` still emits `err\n` on the enclosing stderr stream), and `Vm.expansion_stderr` is cleared once flushed.

#### 5.7.2 Process substitution (`<(cmd)` and `>(cmd)`)
1. **Limits:**
   - Check `Vm.subst_depth >= maxSubstitutionDepth` (`50`): on overflow -> `Fail::SubstDepth { proc: true, cap }` (`exit 126`, `limit_name = "maxSubstitutionDepth"`, `stderr = "bash: Process substitution nesting limit exceeded (<cap>)\n"`).
   - Allocate the highest free fd in `63..=10` (`54` slots total), also capped by `maxFileDescriptors.saturating_sub(10)` (`let cap = 54u64.min(max_fds.saturating_sub(10))`). If `active_proc_subst.len() as u64 >= cap` or no fd in `10..=63` is free, fail with `Fail::ProcSubstCap(cap)` (`exit 126`, `limit_name = "maxFileDescriptors"`, `stderr = "bash: Process substitution limit exceeded (<cap> concurrent)\n"`).
2. **Input process substitution `<(cmd)`:**
   - Run `cmd` in an isolated subshell frame (`subst_depth + 1`, new `bash_pid`, cloned `env`/`arrays`/`cwd`, preserving outer `Fiber.last_exit` — `<(...)` **never** changes `$?`!).
   - Forward any stderr to `Vm.expansion_stderr`.
   - Write captured stdout bytes to VFS path `/dev/fd/<fd>` (granting temporary write permission on `/dev/fd/<fd>` even when `/` is read-only; ensure `/dev/fd` directory exists).
   - Register `ProcSubstEntry { fd, path: b"/dev/fd/<fd>", output_body: None }` on the current command's cleanup list and return `b"/dev/fd/<fd>"` as the expanded word fragment.
3. **Output process substitution `>(cmd)`:**
   - Pre-create empty VFS file `/dev/fd/<fd>` (with temporary `/dev/fd/<fd>` write allowance during the outer command so redirections/commands writing to `/dev/fd/<fd>` succeed even on read-only FS).
   - Register `ProcSubstEntry { fd, path: b"/dev/fd/<fd>", output_body: Some(body) }` and return `b"/dev/fd/<fd>"`.
4. **Command-end drain & cleanup (runs in cleanup phase of every `SimpleCmd` / compound command, even on error):**
   - For each registered `ProcSubstEntry` in order: if `output_body` is `Some(body)`, read the bytes written to `/dev/fd/<fd>` and execute `body` in an isolated subshell frame with those bytes as `stdin` (appending consumer stdout/stderr to the command's output, **without** altering the outer command's `exitCode` / `$?`, except propagating `LimitExceeded`).
   - Unlink `/dev/fd/<fd>` from `Vfs` and release `fd`.

### 5.8 Word splitting (`IFS`) and quote removal

1. **`IFS` resolution:**
   - `env.get(b"IFS")`: if `None` (unset) -> `b" \t\n"` (default). If `Some(b"")` -> splitting is **disabled**.
   - Partition `IFS` characters (by UTF-8 scalar) into `ifs_ws` (characters in `' '`, `'\t'`, `'\n'` that appear in `IFS`) and `ifs_non_ws` (all other scalars in `IFS`).
2. **`split_by_ifs_ex(value, ifs)`:**
   - Emit `bash:expansion:word_split` once per word entering `smartWordSplit` (i.e. inside `expand_words` when the word has an unquoted `CommandSubst`, `ArithExpand`, or `ParamExpand`, `IFS != ""`, and none of the early brace / `@`-array / positional / unquoted-array handlers handled the word).
   - If `value` is empty -> `words = []`, `had_leading = false`, `had_trailing = false`.
   - Skip leading `ifs_ws` (`had_leading = skipped > 0`). If at end -> `words = []`, `had_leading = true`, `had_trailing = true`.
   - If `value[pos]` is in `ifs_non_ws`: push `""` (checking `maxArrayElements`), advance past that `ifs_non_ws` and any following `ifs_ws`.
   - Loop while `pos < value.len()`:
     - Scan `word_start..pos` until any `ifs_ws` or `ifs_non_ws`; push `value[word_start..pos]` (checking `maxArrayElements`). If `pos == value.len()`, `had_trailing = false`, break.
     - Skip `ifs_ws`. If `pos < value.len()` and `value[pos]` is in `ifs_non_ws`: advance 1 scalar, skip `ifs_ws`, and while `pos < value.len()` and `value[pos]` is in `ifs_non_ws`: push `""` (checking `maxArrayElements`), advance 1 scalar, skip `ifs_ws`.
     - If `pos == value.len()`, set `had_trailing = true` (a single trailing non-whitespace delimiter in `"a:b:"` sets `had_trailing = true` and produces `["a", "b"]`, **not** `["a", "b", ""]`, whereas `"a::b"` produces `["a", "", "b"]`).
3. **Joining mixed quoted/literal and unquoted-split segments (`smartWordSplit`):**
   - Walk `WordPart`s left-to-right maintaining `words: KVec<KBytes>`, `current: KBytes`, `has_word: bool`, `has_quoted_segment: bool`:
     - Quoted parts (`SingleQuoted`, `AnsiCQuoted`, `DoubleQuoted`, `Escaped`): set `has_quoted_segment = true`, `has_word = true`, append expanded bytes to `current` without splitting (thus `""` produces `[""]`, and `""$unset` produces `[""]`).
     - Literal/Glob/TildeExpand parts: set `has_word = true`, append expanded bytes to `current` without splitting.
     - Unquoted `ParamExpand` / `CommandSubst` / `ArithExpand`: split expanded string via `split_by_ifs_ex`:
       - `0` split words: if `had_leading && has_word`, flush `current` into `words` and reset `current = ""`, `has_word = false` (so `x=' '; echo a${x}b` -> `a`, `b`!).
       - `>= 1` split words: if `had_leading && has_word`, flush `current` first; append `split[0]` to `current` (`has_word = true`); for `split[1..k-1]`, flush `current` and set `current = split[i]`; if `had_trailing`, flush `current` and reset `has_word = false` (so `x='a b '; echo -$x-` -> `-a`, `b`, `-`!).
   - At end of parts: if `has_word`, push `current`. If `words.is_empty() && has_quoted_segment`, push `b""`.
4. **Quote removal:**
   - Surrounding `SingleQuoted` (`'...'`), `DoubleQuoted` (`"..."`), `AnsiCQuoted` (`$'...'`), `$"..."`, and unquoted `\` escapes are already represented structurally as `WordPart` nodes in L3's AST; assembling expanded `WordPart` bytes produces the quote-removed word while recording which characters came from quoted parts so pathname globbing treats quoted `* ? [` literally.

### 5.9 Pathname expansion over L8a `kernel::glob` and VFS/host mounts

1. **Trigger & escaping:**
   - Skipped entirely when `ShellOpts.noglob` (`set -f`) is `true` or when a word came from a standalone fully-quoted expansion (`quoted == true`).
   - Build a glob-pattern byte string from the word: quoted characters (`SingleQuoted`, `AnsiCQuoted`, `DoubleQuoted`, `Escaped`) have `* ? [ ] \ ( ) |` prefixed with `\`, while unquoted `Glob`, `Literal`, and unquoted expansion results keep their glob metacharacters active.
   - Check `has_unquoted_glob(&pat, shopt.extglob)`: true iff outside `\` escapes there is `*`, `?`, a balanced `[...]` character class, or (when `shopt.extglob` is `true`) `?(...)`, `*(...)`, `+(...)`, `@(...)`, `!(...)`. If false, keep the unescaped word as-is without touching the FS.
2. **Segment splitting & `**` cap:**
   - When `shopt.globstar` is `true`, call `kernel::glob::check_globstar_segments(&pat)`; on `Err(GlobError::TooManyGlobstars { .. })` (`> 5` standalone `**` segments), fail immediately with `Fail::GlobStarsCap` (`exit 126`, `limit_name = "maxGlobOperations"`, `stderr = "bash: Glob pattern has too many ** segments (max 5)\n"`).
   - Split pattern by `/` into path segments (preserving leading `/` for absolute paths vs relative to `Fiber.cwd`, and trailing `/` requiring directory matches). When `shopt.globstar` is `false`, collapse `**+` inside non-globstar mode to `*` (single segment match, no recursive descent).
3. **Resumable directory walk (`GlobWalker`):**
   - Walk candidate directories iteratively using an explicit `KVec` frontier (never Rust recursion!).
   - Every directory entry comparison and `CompiledGlob` work tick increments `glob_ops: u64`; if `glob_ops > maxGlobOperations`, fail immediately with `Fail::GlobLimit(cap)` (`exit 126`, `limit_name = "maxGlobOperations"`, `stderr = "bash: Glob operation limit exceeded (<cap>)\n"`).
   - **VFS vs host mount:** For pure `Vfs` paths, read directory entries via `Vfs` directly. When any candidate directory falls under a `HostMount`, batch all frontier `Readdir` / `Stat` / `Lstat` ops into a single `HostReq::FsBatch` (`Pending::ExpandFs`) per tree depth level so host round-trips stay `O(depth)`.
   - **Dotfile & `.` / `..` rules:**
     - Let `globignore_raw = env.get(b"GLOBIGNORE").map(|e| e.value.as_slice()).filter(|v| !v.is_empty())`.
     - Let `has_globignore = globignore_raw.is_some()`.
     - Let `effective_dotglob = shopt.dotglob || has_globignore`.
     - Entry names `"."` and `".."`: synthesized during `.*` matching *only* when `!shopt.globskipdots && !has_globignore` and the pattern segment explicitly starts with `"."`; never traversed recursively by `**`.
     - Other dotfiles (`name.starts_with(b".")`): `CompiledGlob` enforces leading-`.` protection via `dotglob: effective_dotglob` when `pathname: true`.
   - **Segment match:** Compile each non-`**` segment pattern once via `CompiledGlob::compile(seg_pat, GlobOptions { extglob: shopt.extglob, nocase: shopt.nocaseglob, pathname: true, dotglob: effective_dotglob, max_extglob_depth }, budget)` and match candidate entry names via `compiled.is_match(entry_name, budget, &mut work)`. (On `GlobError::InvalidCharacterRange | GlobError::ExtglobDepthExceeded { .. }`, the segment matches `0` entries.)
   - **Symlinks:** Non-terminal segments follow symlinks to directories (`stat`); terminal segments match even broken symlinks (`lstat`) unless the pattern ends with `/`, which requires `stat` -> directory (`**` recursive descent does **not** follow directory symlinks to prevent symlink cycles!).
   - **`GLOBIGNORE` post-filter (`split_globignore` + `pathname: true`):** If `let Some(raw) = globignore_raw`, split `raw` with `kernel::glob::split_globignore(raw, budget)?` (which splits on `:` outside bracket expressions so `[[:alnum:]]` stays intact, dropping empty items). Compile each ignore pattern `g_i` with `CompiledGlob::compile(g_i, GlobOptions { extglob: shopt.extglob, nocase: false, pathname: true, dotglob: true, max_extglob_depth }, budget)` and drop any matched path `p` (as formatted in output, e.g. `foo.txt` or `dir/foo.txt`) for which `compiled.is_match(p, budget, &mut work)` is `Ok(true)`. Because `pathname: true` prevents `*`, `?`, `[...]`, and extglob groups from matching `/`, `GLOBIGNORE='*.txt'` filters `foo.txt` (and `.hid.txt` via `dotglob: true`) while keeping `dir/foo.txt`!
   - **Sorting:** Sort matched paths in ascending UTF-8 byte (`[u8]::cmp`) order and deduplicate.
4. **Zero-match policy (`nullglob` / `failglob` / default):**
   - `matches.len() > 0`: check `maxArrayElements` and append `matches`.
   - `matches.is_empty()`:
     - If `shopt.failglob` is `true` (`failglob` wins when both `failglob` and `nullglob` are `true`!): fail command-recoverably with `Fail::Failglob`: `stderr = "bash: no match: <raw_pattern>\n"`, `exit = 1` (command does **not** run; script continues at next statement!).
     - Else if `shopt.nullglob` is `true`: drop the word (`0` results).
     - Else (default): emit the unescaped word literally (`1` result).

### 5.10 Shell options in expansion

- **`nounset` (`set -u` / `set -o nounset`):**
  - Referencing an unset scalar `$v` / `${v}`, unset array element `${a[0]}`, unset positional `$1` (`1 > $#`), or unset `$!` fails **fatally** with `Fail::Nounset`: `stderr = "bash: <param>: unbound variable\n"`, `exit = 1` (aborts script/subshell).
  - **Exemptions (do NOT error under `set -u` when unset/empty):**
    1. `$@`, `$*`, `"$@"`, `"$*"`, `${@}`, `${*}`, `$#` when `$# == 0`.
    2. `"${arr[@]}"`, `"${arr[*]}"`, `${arr[@]}`, `${arr[*]}`, `"${#arr[@]}"`, `"${#arr[*]}"`, and standalone `"${!arr[@]}"`, `"${!arr[*]}"`, `${!arr[@]}`, `${!arr[*]}` even when `arr` is empty `a=()` or completely unset! (Remember the `3.6.0` composite/scalar `ArrayKeys`/`VarNamePrefix` detail in §5.4.10: inside composite `"x${!arr[@]}"` or `x=${!arr[*]}`, `parameter == ""` triggers `bash: : unbound variable\n`.)
    3. Parameter expansions carrying `:-`, `-`, `:=`, `=`, `:+`, `+`, `:?`, or `?` (`skip_nounset = true` on the outer parameter; `${unset?}` runs `ErrorIfUnset`, not `Nounset`).
- **`noglob` (`set -f` / `set -o noglob`):** Disables pathname expansion (§5.9) everywhere; pattern matching inside `${v#pat}`, `${v/pat/rep}`, `case`, and `[[ ]]` remains active.
- **`shopt` defaults:** `globskipdots = on`; `extglob`, `dotglob`, `nullglob`, `failglob`, `globstar`, `nocaseglob`, `nocasematch`, `expand_aliases`, `lastpipe`, `xpg_echo` all `off`.
