# @sentropic/bash-jco

Option D binding of `@sentropic/bash`: the same zero-dependency, WASM-first bash sandbox,
with the JavaScript binding generated by the pinned guarded `jco` toolchain instead of the
default first-party canonical-ABI binding.

```js
import { Bash } from "@sentropic/bash-jco";
import { Bash as BrowserBash } from "@sentropic/bash-jco/browser";

const bash = new BrowserBash();
await BrowserBash.precompile();
console.log((await bash.exec("echo hi")).stdout);
```

The package installs alone and offline: no dependencies, no install script. It carries the same
component bytes and WIT contract as `@sentropic/bash`; only the JavaScript binding differs.
The default shell uses ordinary initialization over the same final component (no snapshot
restore). See `DIVERGENCES.md` for the intended differences from the reference behavior.
