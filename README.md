# @sentropic/bash

A zero-dependency, WASM-first bash sandbox. It is a clean-room reimplementation with functional parity to
[`vercel-labs/just-bash`](https://github.com/vercel-labs/just-bash), designed for fast startup, fast
builtins and a default-deny security model. It is benchmarked against just-bash and
[MoonBash](https://github.com/Haoxincode/MoonBash).

Status: bootstrap. Design, spec and plan are in progress under the h2a harness (`rules/MASTER.md`).
